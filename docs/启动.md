# 本地开发启动

`corepack yarn dev` 不是热更新，也不是“打开已经编好的应用”。它每次都会把发布前的准备再跑一遍，窗口要等这些步骤全部结束才出现。刚才一次完整启动大约 5 分钟；窗口本身在准备结束后马上就开了。

## 每次 `yarn dev` 在做什么

根目录脚本是这四步串起来的：

```sh
yarn market:prepare && yarn aa:prepare-release && yarn workspace dsh-community-market build && yarn workspace dsh-plugin-desktop dev
```

1. **刷新社区市场。** `market:prepare` 去 npm 核对 `dshmarket` 的最新版。版本一变，Yarn 就会重装并改锁文件。刚才这次从 1.66.20 升到 1.66.21，这一段只要几秒。
2. **重新准备 Agents Anywhere。** `aa:prepare-release` 每次都从 GitHub 浅克隆官方 `main`，在临时目录里安装依赖、编译桥接包、打成 tgz，再链回桌面仓库。刚才选中的提交是 `bc436f30c61eb449133f74f01ea27ef12611f6c4`。这一段是大头。
3. **编译社区市场。** `dsh-community-market` 的客户端包很快，刚才大约 40 毫秒。
4. **完整编译桌面插件，再打开窗口。** `dsh-plugin-desktop` 的 `dev` 本身又是四步：

   ```sh
   yarn run build && yarn run prepare:electron-native && yarn run prepare:runtime && node lib/bin.js
   ```

   - 全量编译插件（tsdown、Vite、类型检查）。
   - 为当前 Electron 编译原生模块 `fs-ext`。编译器警告来自这个模块，不影响启动。
   - 准备本机运行时。macOS 上会同时做 **mac-arm64** 和 **mac-x64** 两套（Python 与 Node 版本以运行时锁文件为准，刚才是 Python 3.12.14、Node 24.21.0）。这一步每次都会删掉 `.desktop-build/runtime` 再铺一遍；下载包有缓存，铺运行时没有跳过。
   - 最后才执行 `node lib/bin.js`，这时 Electron 窗口才出来。

日志里出现下面这一行，就说明进程已经起来了：

```text
dsh-plugin-desktop: outbound proxy = http://127.0.0.1:7890/ (source: system, no_proxy: ...)
```

`source` 为 `system` 表示用的是系统代理。后面 DeepSeek 账号接口返回 200，也只说明账号请求通了，不代表前面的准备还在跑。

Beta 用 `corepack yarn dev:beta`，实验性 Next 用 `corepack yarn dev:next`。两条都会先跑市场刷新和 Agents Anywhere 准备。日常改桌面功能时，先在 `dsh-plugin-desktop-beta/` 里改，再同步到 `dsh-plugin-desktop/`。`corepack yarn dev` 启动的是 Stable（`dsh-plugin-desktop`）。

## 想少等的时候怎么开

代码已经编过、只是想再开一次窗口：

```sh
cd dsh-plugin-desktop
node lib/bin.js
```

这条跳过市场刷新、Agents Anywhere、全量编译和运行时重建。前提是 `lib/bin.js` 和 `.desktop-build/runtime` 已经由上一次成功的 `dev` 或 `prepare:runtime` 生成。

改了 `dsh-plugin-desktop` 的源码，需要重新编译，但不用再拉市场和 Agents Anywhere：

```sh
corepack yarn workspace dsh-plugin-desktop dev
```

它仍会全量编译、编译 `fs-ext`，并重新铺两套 macOS 运行时。

`corepack yarn start` 比 `dev` 少了 Agents Anywhere 和全量编译，但仍然会先 `market:prepare`，再 `prepare:runtime`（同样会删掉并重铺运行时），然后才 `node lib/bin.js`。只想马上看到窗口时，直接跑上面的 `node lib/bin.js`。

## 第一次在这台机器上启动

```sh
git submodule update --init --recursive
corepack yarn install --immutable
corepack yarn dev
```

Node 用 `^22.19.0` 或 `>=24.0.0`，Yarn 用仓库锁定的 4.18.0（通过 Corepack）。`deepseek-harness/` 是上游子模块，桌面功能不要改里面的文件。
